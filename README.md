# カルダシェフ文明マップ

宇宙誕生（138億年前）から、Type I〜III の「もしもの」未来文明までを、ひとつの時代スライダーで行き来できるインタラクティブ・ガイドブックです。基準は「現在の地球（2026年）」です。

6つのページがあり、6番目の「地球大全」は、地球の外から来た知的存在のための「この世のしくみ」の読みもの（<!-- eb-count -->序＋11部・68章<!-- /eb-count -->）です。

**▶ 公開ページ：https://ksan1333.github.io/kardashev-map/** ／ **地球大全：https://ksan1333.github.io/kardashev-map/#earth-book**

## できること

| タブ | 内容 |
|---|---|
| 01 全体マップ | 12分野の現在地、エネルギー利用量で見る文明の歩み、Type I〜III 文明ガイド、SFノート（文明の5段階・EOI/FOI/UOI・言語と記憶） |
| 02 年表 | 宇宙・地球史・世界史の3つの年表。GitHub のブランチのような枝分かれ表示で、出来事を押すと3Dの場面が出る。歴史シアター（3D）付き |
| 03 宇宙・地球・ミクロ | 宇宙の本線は5段階（地球と月→太陽系→近くの恒星から天の川銀河まで→大規模構造→宇宙の形）に統合し、その先を空想の上位層（マルチバース→法則の海→オムニバース→不可能世界→無）として点線で延長。分岐は、天体の中（断面）11、銀河の中7、別の宇宙15、法則の海の島4、オムニバースの世界6。枝分かれ図はホイール・ドラッグ・＋−全体でズームできる。星雲は立体（レイマーチング）。惑星・月・太陽・冥王星にズームインすると「世界地図」のページでその天体の地図（地名・ズーム付き）が開く。世界地図（3Dジオラマ40か所＋国別）、ミクロは本線11段階（生き物→体と器官→細胞→生体分子→分子→物質→原子→原子核→クオーク→素粒子→量子）＋プランク長より下（仮説→空想）3段階＋分岐（細胞の中／微生物・ウイルス／理論）。ズームインすると選んでいるものの「中」へ進み、ミクロの「描けない底」と宇宙の最外「無」が一周してつながる |
| 04 系統樹 | 17分野・約1,600要素の系譜（誕生・分岐・合流・消滅）を、分野ごとに独立した時間軸で表示。時間軸は「時代ごと」（各時代に幅を割り当てる・既定）と「実際の年数」を切り替えられる。2026年より先は「もしも」（点線）で5つの世界線と、SFノートの構想【SF】に分かれる |
| 05 宇宙の法則 | 4つの力、公式、物理定数、素粒子、周期表（118元素）、分子、未解決問題 |
| 06 地球大全 | 数・物質・宇宙・地球・生命・人間・社会・文化・技術・歴史・いまとこれからを、表と図で順に説明する読みもの。目次・本文検索・章の中の見出し・前後の章（下の「地球大全」） |

- 画面上の **時代バー（カルダシェフ・スライダー）** で時代を選ぶと、すべてのページがその時代の姿に切り替わります。時代は等間隔に並んでいて、つまみのドラッグ・‹ › ボタン・時代名を押して出る一覧のどれでも選べます。
- **全体検索**：`/` キーまたは `Ctrl`+`K`（スマホは上の🔍）で、出来事・国・元素・生き物・天体・発明などを横断検索し、その場所へ移動できます。

### 画面の構成（PC・タブレット・スマホ）

| 画面の幅 | 構成 | 詳細パネル |
|---|---|---|
| PC（1280px〜） | 左にページのメニュー（年表・宇宙は中の切り替えも）、上に固定の時代バー | 図の右。図と本文を左に寄せる（時代バーの幅はそのまま） |
| PC（1100〜1279px） | 同上 | 図の右に重ねて出す |
| タブレット（768〜1099px） | 左のメニューはアイコンだけの細い列、上に時代バー | 図の右に重ねて出す |
| スマホ（〜767px） | 上のバーに時代ボタン・検索・使い方、下にページのタブ。時代は下から出るシートで選ぶ | 画面の下から出る（上下にスワイプで広げる／たたむ） |

どのページも同じ部品を、同じ順番・同じ見た目で使っています。

| 部品 | 中身 |
|---|---|
| 見出し | ページ名・1行の説明・「見方と操作」（長い説明はここにたたむ） |
| 切り替え | 四角いボタンの並び（年表の宇宙／地球史／世界史、宇宙／世界地図／ミクロ、法則の4つの力／周期表…） |
| 絞り込み | 左に何を選ぶ行かのラベル（分野・天体・表示・種類・地域・見るもの）、右にチップ。スマホは横にスクロール |
| 図の操作バー | 年表・系統樹・地図・3Dの上に必ず付く。左にそのページの切り替え、右に −・＋・全体・⤢（全画面。PCは `F` キー） |
| 詳細パネル | 出来事・要素・国・元素・地名などを押すと出る。どのページも同じ場所・同じ見た目で、× か `Esc` で閉じる |

- 図はドラッグで移動、ホイール（スマホは2本指のピンチ）か操作バーの −・＋ で拡大縮小できます。
- 宇宙・ミクロの「いま見ているもの」は、操作バーの「詳細」で出す／しまうを切り替えます。PC（1280px〜）とスマホでは出た状態で始まり、図に重ねて出す幅（768〜1279px）では「詳細」を押したときだけ出ます（しまっている間は図の下に出ます）。

- ページの上に「目次」と本文の検索欄があります（スクロールしても、時代バーの下に残ります）。検索で見つかった言葉は本文の中で光ります。
- 行き先は URL の `#` で表します：`#earth-book`（表紙）、`#eb-章のid`（章）、`#eb-章のid.番号`（章の中の見出し）、`#eb-q=語`（本文検索の結果）。全体検索（`/` キー）にも、章と見出しが出ます。
- 前後の章は、章の終わりのボタンか `←` `→` キー。章の中の見出しは、題名の下（1280px以上は右）の一覧から。
- 最後に読んでいた章を覚えていて、表紙の「続きから」で戻れます（ブラウザの localStorage）。
- 地球大全は「いまの地球（2026年）」の説明なので、時代バーで時代を変えても中身は変わりません。
- 前の地球大全の URL（`earth.html`、`earth.html#章のid`、`earth.html?q=語`）は、`index.html` の同じ場所へ送ります。
- 時期で変わる数字（人口・GDP・死因・エネルギーなど）は、各章の終わりに出典と年を書いています。

### 章の足し方

`src/eb_pNN.js`（NN は部の番号。ファイル名の順に並ぶ）に書きます。

```js
EB.part("culture","文化","🎨","部の説明");          // 部を始める
EB.add({id:"religion",ic:"🛐",t:"信仰と宗教",       // id は全章で重ならないこと
        k:"検索用の言葉",c3d:"un|cell",            // c3d は立体図（なくてよい）
        h:`<p class="eblead">…</p><h4>見出し</h4>${tbl([...],[...])}`});
```

部品は `src/eb_core.js` にあります：`tbl`（表）、`bar`（棒グラフ）、`fig`（図）、`cards`、`flow`、`note`、`src`（出典）、`see("章のid","文字")`（ほかの章へ）、`map("timeline","文字")`（文明マップのほかのページへ）。`<h4>` が章の中の見出しになり、検索にも使われます。ビルドすると、id の重なりはエラーに、行き先のない `see()` は警告になります。

## ビルド

Node.js があれば追加のインストールは不要です。

```bash
node build.js            # index.html と earth.html（転送）を作る（three.js r128 は CDN から読み込み）
node build.js --local    # index.local.html と earth.local.html を作る（node_modules/three を使うオフライン確認用）
```

`src/` を編集したら `node build.js` を実行して、`index.html` と `earth.html` も一緒にコミットしてください。`*.local.html` はコミットしません。

## 注意

- 数値は概数です。2026年より先の内容（Type I〜III）は予測・目標・想像にもとづく「もしもの世界」で、事実とは区別しています。
- 「SFノート」とマルチバースの別の宇宙は創作（空想）で、【SF】や「空想」の印で区別しています。
- 3Dモデルは特徴をつかむための簡略表現で、大きさや色は実物どおりではありません。
